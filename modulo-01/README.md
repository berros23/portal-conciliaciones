## Criterios para darlo por terminado

- 1.1: la ficha está completa con datos reales, no inventados.
- 1.2: el script corre sin errores y respondiste las preguntas marcadas con `PREGUNTA`.
- 1.3: cada acción tiene método, ruta, código de éxito y al menos dos errores posibles.
- 1.4: `python ejercicio_1_4_regla_pendientes.py` muestra todas las verificaciones en ✅.
