# Portal de Conciliaciones

Proyecto de aprendizaje full stack. Cada módulo agrega una pieza real a un portal
donde un analista consulta lotes, revisa diferencias y registra decisiones.

## Avance

- [ ] Módulo 1 · Cómo funciona la web (HTTP, APIs, cliente-servidor)
- [ ] Módulo 2 · Git y GitHub
- [ ] Módulo 3 · Python como cliente de APIs
- [ ] Módulo 4 · Backend con FastAPI
- [ ] Módulo 5 · PostgreSQL
- [ ] Módulo 6 · Autenticación y autorización
- [ ] Módulo 7 · Frontend básico (HTML, CSS, JavaScript)
- [ ] Módulo 8 · React
- [ ] Módulo 9 · Pruebas
- [ ] Módulo 10 · Linux y Docker
- [ ] Módulo 11 · Nube y CI/CD
- [ ] Módulo 12 · Arquitectura, seguridad y costos

## Cómo ejecutar

```bash
py -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```
